# Hoy releases

Downloads and the update feed for **Hoy**, a calm day planner for the Mac (also on iPhone and iPad).

- Download the latest version from the [Releases](https://github.com/Jason9347/hoy-releases/releases/latest) page, or from [yeison.co.uk](https://yeison.co.uk).
- Hoy updates itself; `appcast.xml` is the feed it checks.

Your plans stay on your devices and in your own iCloud. Hoy's source code is not published here.
